## 사용자 규칙·기억 요청
- **프로젝트가 삭제돼도 레포만으로 관리·복구할 수 있어야 한다.** 대화에서 정한 것·지침 문구·기준값은 전부 레포에 남긴다.
- **원본은 무조건 깃 레포.** 레포에서 먼저 고치고, claude.ai 프로젝트 문서·자료집은 레포에 맞춘다 (CLAUDE.md).
- 답변은 한국어로 짧고 쉽게.
- 작업 시작 시 이 파일과 docs/인수인계/ 최신 날짜 파일을 먼저 읽고 '남은 일'부터 이어간다.
- **변경은 반드시 레포에 커밋·머지(main 푸시)** 한다: ./save.sh 실행, 결과 한 줄 보고. 다른 브랜치면 main 으로 머지.
- "인수인계" = 이 파일과 날짜 파일 갱신 후 커밋·머지, 경로만 알려줌.
- "기억해" = 이 섹션에 한 줄 추가.
- 디자인·의상은 매우 중요: 한국 정통 복장 + 세련된 퓨전, 레퍼런스는 핀터레스트.
- 이름은 순우리말 (중국풍 금지).
- 큰 틀이 바뀌면 버전 업해서 HTML 작성.
