# 로판ai영화 · 문서 구조 안내

> 여러 작품을 만들 수 있도록 **공통 규칙**과 **작품별 문서**를 나눠 관리한다.
> 현재 구조 버전: **v3.0** · 시나리오 작성 편집기 **v2.0**
> 모든 자료는 **통합 자료집 한 페이지**에서 봅니다: [로판ai영화 · 통합 자료집](https://claude.ai/artifact/KnEAL5qqyTcteDdstdFyxC)
> **원본은 깃허브 레포**: https://github.com/similefor/Ai-drama (main). claude.ai 프로젝트 문서와 자료집은 레포의 사본이며, 다르면 레포가 맞다. 작업 순서는 레포의 CLAUDE.md, 커밋은 `./save.sh`.

## 폴더 구조

```
claude/
├─ 00_구조_안내.md              ← 이 파일 (구조, 작품 목록, 버전 기록)
├─ 공통/                         ← 모든 작품에 쓰는 규칙·자료 (작품 이름 넣지 않음)
│  ├─ 01_기본_규칙.md
│  ├─ 02_드라마웹툰_핵심6.md
│  ├─ 03_AI캐릭터_핵심6.md
│  ├─ 04_디자인_의상_공통자료.md
│  ├─ 05_요구사항_목록.md
│  ├─ 06_제작_참고자료_오픈소스.md   ← 시나리오·AI 영상 제작 오픈소스 정리
│  └─ 07_시장조사.md               ← 별도 링크 페이지 '시장조사'로 발행
├─ 지침/                         ← 복사용 지침서 (내용만, 계속 추가)
│  ├─ 공통_지침.txt              ← 모든 프로젝트 (개인 설정 지침 칸)
│  └─ 프로젝트_지침.txt          ← 이 프로젝트 지침 칸
├─ 관리/
│  └─ 01_복구_가이드.md          ← 프로젝트가 지워져도 레포만으로 복구
├─ 작품/
│  ├─ _템플릿/                   ← 새 작품 시작용 빈 양식
│  │  ├─ 01_설정.md
│  │  └─ 02_디자인.md
│  └─ 01_그믐과_서리/            ← 작품 1
│     ├─ 01_설정.md             (세계관·인물·로맨스 대상·구조·훅)
│     └─ 02_디자인.md           (캐릭터 의상·색·배경)
└─ tools/                        ← HTML 열람 페이지를 만드는 틀
   ├─ build.py                  (작품 목록·메뉴 구성·버전 설정 → out/hub.html 한 개 빌드)
   ├─ hub.html                  (통합 자료집 골격: 햄버거 메뉴 3단계)
   ├─ editor.html               (시나리오 작성 편집기 부품: 통합 페이지 안에 들어감)
   └─ presets/<작품코드>.json    (작품 입력값 + 분위기·톤 보드 "mood")
```

## 메뉴 구성 (통합 자료집 · 햄버거 메뉴 3단계)

```
⌂ 홈                         ← 작품 카드 · 도구 카드
작품                          ← 1단계: 분류
 └ ● 그믐과 서리              ← 2단계: 작품
    ├ 분위기·톤 (비주얼)       ← 3단계: 문서
    ├ 작품 설정
    └ 작품 디자인
도구
 └ 시나리오 작성 편집기
시장·제작 자료
 ├ 시장조사
 ├ 제작 참고 (오픈소스)
 └ 디자인·의상 공통자료
공통 규칙
 ├ 기본 규칙
 ├ 드라마·웹툰 핵심 6
 └ AI 캐릭터 핵심 6
지침 (복사용)
 ├ 공통 지침 · 모든 프로젝트   [전체 복사] 버튼
 └ 프로젝트 지침 · 로판ai영화  [전체 복사] 버튼
관리
 ├ 요구사항 목록
 ├ 구조 안내·버전
 └ 복구 가이드
```

- ☰ 버튼으로 메뉴를 열고 닫는다. 넓은 화면(1100px 이상)에서는 왼쪽에 고정, 휴대폰에서는 서랍처럼 열린다.
- 상단 바에 지금 위치(예: 작품 › 그믐과 서리 › 분위기·톤)가 보인다.
- 분위기·톤은 시나리오 외적인 비주얼 기준이라 작품 아래 **별도 항목**으로 둔다.

## 시나리오 작성 편집기
- 입력칸(세계관, 인물, 악역, 원하는 것, 작성 요청)을 채우면 **기본 규칙이 들어간 작성 프롬프트**가 자동으로 만들어진다.
- 'Claude로 시나리오 작성' 버튼으로 그 자리에서 시나리오를 쓰거나, 프롬프트를 복사해 대화창에 붙여넣는다.
- 작성 요청: 기획안 / 회차별 훅 표 / 특정 화 대본(웹툰 콘티·숏드라마 씬) / 인물 의상 시트
- 열기: 통합 자료집 › 도구 › 시나리오 작성 편집기
- 메뉴가 **시나리오 입력 / 분위기·톤** 두 개로 나뉜다. 분위기·톤은 '프롬프트에 포함'을 켰을 때만 작성 프롬프트에 들어간다 (대본·의상 시트에 추천).
- 작품 불러오기 목록은 tools/presets/*.json 에서 온다. 기본 규칙(공통/01 1~6장)은 빌드할 때 자동으로 들어간다.

## 새 작품 추가 방법
1. claude/작품/_템플릿/ 의 두 파일을 claude/작품/NN_작품명/ 으로 복사해 채운다.
2. claude/tools/presets/NN_작품명.json 을 만든다 (작품 입력값 + mood).
3. claude/tools/build.py 의 WORKS 에 한 줄 추가 (제목, 소개, 색, 문서 목록).
4. 빌드 → 같은 통합 자료집 아티팩트에 덮어써 발행. 메뉴의 '작품' 아래에 자동으로 생긴다.

## HTML 열람 페이지
- **통합 자료집 1개**에 모든 작품·공통 자료·편집기·시장조사를 담는다 (v3.0부터).
- 골격은 tools/hub.html 하나, 편집기는 tools/editor.html 을 부품으로 끼워 넣는다.
- 이전에 따로 만든 '시나리오 작성 편집기', '시장조사' 페이지는 통합 페이지로 대체됐다 (더 이상 갱신하지 않음).
