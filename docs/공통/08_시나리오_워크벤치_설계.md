# 시나리오 워크벤치 설계 · v1.0 시안

## 목적
여러 드라마·웹툰·AI 숏드라마 프로젝트를 독립 관리하고, 요구사항 정의부터 시장조사·세계관·디자인·훅·회차 대본·검수까지 연결한다.

## 제작 흐름
1. 요구사항: 장르, 형식, 타깃, 플랫폼, 회차, KPI, 필수·금지 조건
2. 시장·레퍼런스: 시장 가설, 경쟁작, 시청자, 출처, 날짜, 인사이트, 적용점
3. 세계관·캐릭터: 세계 규칙, 고정 캐논, 미확정 설정, 인물 욕망·상처·비밀·변화·말투
4. 디자인·연출: 아트 디렉션, 색·조명·질감, 의상, 공간, 소품, 카메라, AI 일관성
5. 훅·회차: 오프닝 훅, 회차 목표, 중간 전개, 엔딩 클리프행어
6. 시나리오: 회차별 씬, 장소·시간, 행동, 대사, 연출·사운드
7. 검수·프롬프트: 캐논 충돌, 훅, 페이스, 영상 구현성, 타깃 적합성 점검

## 공통 공식
- 장면: 목표 → 장애물/갈등 → 선택/행동 → 결과/변화
- 오프닝 훅: 즉시 이해되는 상황 + 욕망/위협 + 예상 밖 정보 + 질문
- 회차 엔딩: 반전·위협·관계 변화·선택 강요·비밀 공개 중 하나로 다음 화의 질문 생성
- 캐릭터: 욕망·상처·신념을 기반으로 행동. 편의를 위해 성격을 바꾸지 않음
- 세계관: 확정 캐논 유지, 미확정 설정 임의 확정 금지
- 영상: 설명보다 행동·표정·시선·소품·공간으로 전달
- AI 연속성: 얼굴·헤어·의상·소품·장소·광원·화면비를 일관되게 명시
- 저작권: 레퍼런스의 분위기·기법만 참고하고 장면·대사·고유 설정 복제 금지

## v1.0 구현 범위
- 작품 생성·선택·복제·삭제
- 브라우저 localStorage 자동 저장
- 전체 JSON 백업·복원
- 요구사항·조사 기록·세계관·캐릭터·디자인·회차·대본 관리
- 공통 지침이 포함된 AI 프롬프트 생성·복사·TXT 저장
- Markdown 내보내기

## 시안의 한계와 후속 작업
- 데이터는 현재 브라우저 localStorage에 저장되어 기기 간 동기화되지 않는다.
- 웹 검색, 이미지 생성, AI API 호출은 아직 연결되지 않았다.
- 사용자 계정·서버 DB·공동 편집·버전 비교·문서 간 캐논 충돌 자동 검사는 후속 버전 범위다.
- 기존 문서 빌드 파이프라인과 데이터 자동 동기화는 후속 개발에서 연결한다.
