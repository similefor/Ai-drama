# 디자인·의상 공통 자료 (모든 작품)

> 모든 작품에서 디자인과 의상은 **가장 중요한 요소 중 하나**다.
> 이 파일은 자료를 찾을 때마다 계속 업데이트한다. 맨 아래 '업데이트 기록'에 남긴다.
> 디자인 레퍼런스는 **핀터레스트**를 기본으로 참고한다 (11번 경로 목록).

---

## 0. 의상 디자인 원칙

**핵심 방향: 한국 정통성 있는 복장 + 세련된 퓨전**

1. **정통이 뼈대다** — 옷의 종류·구조·여밈·실루엣은 실제 한복(당의, 원삼, 철릭, 전복, 도포 등)을 그대로 따른다. 이름과 형태를 정확히 쓴다.
2. **퓨전은 '세련됨'으로만** — 소재(레이스·벨벳·가죽), 재단(더 슬림한 소매, 정돈된 라인), 색 조합, 장신구 디테일로 현대적·고급스러운 느낌을 준다. 형태 자체를 서양 옷으로 바꾸지 않는다.
3. **한국풍 8 : 서양풍 2** — 한눈에 "한국 옷"으로 읽혀야 한다.
4. **옷 = 캐릭터 설명서** — 신분, 성격, 숨긴 비밀이 옷에 드러나게 한다.
5. **색으로 신분과 관계를 말한다** — 오방색과 신분별 색 체계를 활용.
6. **변화는 옷으로 보여준다** — 주인공이 변하면 의상도 바뀐다 (예: 무녀복 → 여제의 예복).
7. **중국·일본 복식으로 보이면 실패** — 한푸·기모노처럼 읽히는 요소는 뺀다.

**세련된 퓨전 체크리스트**
- [ ] 옷 이름을 정통 한복 이름으로 말할 수 있는가?
- [ ] 서양 요소가 소재·디테일·소품 선에서 멈췄는가?
- [ ] 색이 3가지 안쪽으로 정리되어 있는가? (주색 / 보조색 / 포인트)
- [ ] 장신구가 한국 전통 장신구(비녀, 뒤꽂이, 떨잠, 노리개 등)인가?
- [ ] 실루엣만 봐도 한국 옷으로 보이는가?

## 1. 여성 궁중·예복 (황실·귀족 여성)

| 옷 | 특징 | 쓰임 |
|---|---|---|
| **적의** | 꿩 무늬가 들어간 왕비의 최고 예복 | 책봉, 혼례 같은 가장 큰 의식 |
| **원삼** | 소매가 매우 넓고, 소매 끝에 색동과 흰 한삼을 닮 | 왕실·귀족 여성 예복 |
| **당의** | 보통 저고리보다 길고 밑단이 둥글며 옆이 깊게 트임, 소매 끝 흰 거들지 | 저고리 위에 덧입는 작은 예복 |
| **활옷** | 화려한 자수의 혼례복 | 혼례 |
| **흉배** | 가슴·등에 붙이는 문양 (봉황 = 여성 예복) | 신분 표시 |

**원삼 색 = 신분** (실제 조선 기록 기준)

- 왕비: 홍색
- 세자빈: 녹색, 자주색
- 후궁: 주로 녹색·남색 (총애받으면 자주색 가능)
- 공주: 녹색
- 궁녀: 녹색·남색·흑색

## 2. 무녀복

- **무복**은 굿을 할 때 신을 상징하기 위해 입는 옷이다.
- 섬기는 신에 따라 옷이 바뀌고, **성별에 구애받지 않고 중성적으로** 섞어 입는 게 특징이다.
- 주요 겉옷:
    - **홍철릭:** 붉은 철릭. 무관 옷 형태라 걸크러쉬와 잘 맞는다.
    - **전복:** 소매 없이 앞뒤·옆이 트인 남색 조끼형 겉옷.
    - **장군치마:** 남색 치마 + 하늘색 저고리.
    - **호구치마:** 홍색 치마.
- 머리: **주립**(붉은 갓)이나 **꽃갓**.

⚠️ **주의:** 흰 저고리 + 빨간 치마 조합은 일본 무녀(미코) 복장처럼 보여 오해받기 쉽다. 무녀 캐릭터 의상에서는 **피하거나 확실히 한국식 디테일을 더한다.**

---

## 3. 무관·군복

| 옷 | 특징 |
|---|---|
| **철릭** | 무관의 겉옷. 상의와 주름 잡힌 치마가 이어진 형태. 초기엔 소매가 좁고 후기로 갈수록 넓어짐 |
| **동다리(협수)** | 철릭을 간소화해 소매를 좁히고 허리 주름을 없앤 활동복 |
| **전복** | 소매 없는 반팔 겉옷. 소속을 표시하는 용도 |
| **구군복** | 전립 + 동다리 + 전복 + 전대 + 목화(신발). 무관 최고의 차림 ('사또 옷'으로 알려짐) |
| **전립** | 무관 모자. 높은 무관은 공작 깃털·옥 장식을 닮 |

## 4. 색 체계

**오방색** = 청·백·적·흑·황, 각각 동·서·남·북·중앙을 상징한다. 음양오행 사상에서 왔다.

- 잡귀를 물리치는 의미, 나이·혼인 여부·신분 표시로도 쓰였다.

---

## 5. 장신구

| 장신구 | 특징 | 연출 팁 |
|---|---|---|
| **비녀** | 쪽머리 고정용. 긴 '잠'과 ∩모양 '채' 두 종류 | 성인식 상징. 비녀를 주고받는 장면 = 관계의 증표 |
| **뒤꽂이** | 쪽머리 뒤에 덧꽂는 장식. 끝이 뾰족함 | 끝이 뾰족해 숨긴 무기로 쓸 수 있음 |
| **떨잠** | 큰머리에 꽂는, 흔들리는 장식 | 즉위식·혼례 같은 큰 의식 |
| **첩지** | 왕비·명부가 가르마 위에 얹는 장식 | 신분 표시 |
| **노리개** | 저고리 고름에 다는 화려한 장식 | 둘만의 신호, 둘의 색을 섞는 소품 |

- 첩지·떨잠은 상류층만 쓸 수 있었다 → 천민 인물이 쓰면 신분 반전 장면이 된다.

## 7. 서양 요소 넣는 법 (2할만, 세련되게)
- **소재:** 레이스(소매 끝 거들지 대신), 벨벳, 트위드, 얇은 가죽
- **재단:** 소매·몸판을 조금 더 슬림하게, 선을 정돈해 현대적인 인상
- **디테일:** 가죽 장갑, 가죽 전대, 금속 버클
- **소품:** 회중시계, 유리 등불, 망토, 단검
- ❌ 피할 것: 코르셋 드레스, 서양 왕관, 퍼프 소매 드레스 → 한국풍 중심이 무너진다.

## 12. 문양과 금박

**문양은 '말 없는 대사'다.** 옷의 무늬만 봐도 신분과 바람을 알 수 있게 쓴다.

- 조선에서는 **용과 봉황** 무늬를 왕실이 독점하고 민간은 쓰지 못하게 했다.
- **금박**도 왕실 문화였다. 조선은 유교 사회라 왕실 외에는 금박을 쓸 수 없었고, 왕비·공주·옹주의 혼례복과 예복을 장식했다.
- 궁중 예복은 옷감과 색뿐 아니라 **무늬로 지체를 구별**했다.

**문양별 의미와 작품 활용**

| 문양 | 의미 | 연출 팁 |
|---|---|---|
| 용 (운룡문) | 왕권, 하늘의 힘 | 황제·황태자 전용. 함부로 쓰면 반역 |
| 봉황 (서운봉황문) | 왕비, 태평성대 | 황후·여제의 흉배 |
| 학 | 장수, 고결함 | 사대부·문관 |
| 모란 | 부귀, 영화 | 황후·귀족 부인 |
| 석류·복숭아·불수 (도류불수문) | 다산, 장수, 복 | 황후의 예복 (황실 핏줄에 대한 집착) |
| 박쥐 | 복(蝠 = 福과 발음이 같음) | 노리개·장신구 |
| 구름 | 길상, 하늘 | 배경 문양, 무녀의 신성함 |
| 수(壽)·복(福) 글자 | 장수와 복 | 금박 치마단·댕기 |
| 연꽃 | 청결, 불교 | 무녀촌·사당 |

**금박 표현 기법 (작화 참고)**

- **인금:** 얇은 금박을 풀로 찍어 붙임 → 반짝이는 평면 문양
- **직금:** 금실로 옷감을 짤 때 무늬를 넣음 → 은은한 광택
- **금사자수:** 금실로 수를 놓음 → 입체감, 전투복·흉배에 적합

## 13. 궁궐·건축

**단청** = 목조 건물에 오방색으로 칠한 장식. 이름 자체가 '붉은색과 푸른색'이라는 뜻이다.

- 오방색(청·백·적·흑·황)이 기본이고, 음양오행 사상을 담는다.
- 조선 초에는 민가에서도 썼지만, 사치스럽다는 이유로 세종 때 붉은 칠 사용을 금하는 등 점점 궁궐·사찰 중심으로 줄었다.
- 건물 등급에 따라 단청의 화려함이 달랐다 (모로단청, 금단청 등).

👉 **연출 원칙:** 권력 공간일수록 정통, 비밀·이방의 공간일수록 퓨전.
