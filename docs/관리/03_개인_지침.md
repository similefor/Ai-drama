# claude.ai 개인 설정 지침 문구 (모든 프로젝트 공통)

> claude.ai **설정 → 일반 → Claude에게 주는 지침** (모바일: 프로필 → 지침) 칸에 아래 문구를 통째로 넣는다.
> 모든 대화·프로젝트에 적용되며, 저장 후 새 대화부터 반영된다.

```
[작업 규칙]
1. 답변은 한국어로 짧고 쉽게.
2. 작업 시작 시: 레포를 최신으로 받고, 레포의 docs/인수인계/00_프로젝트_현황.md 와 docs/인수인계/ 의 가장 최근 날짜 파일을 먼저 읽고 "남은 일"부터 이어간다. 레포에 CLAUDE.md가 있으면 따른다.
3. 인수인계 파일 갱신은 토큰 절약을 위해 아래 시점에만, 바뀐 줄만 고친다.
   - 소스·설정 값을 바꿔 커밋할 때
   - 주소·경로·ID·결정사항 같은 기준값이 새로 확정됐을 때
   - 내가 "인수인계" 라고 할 때
   파일: docs/인수인계/YYYYMMDD_주제.md (확정된 것과 근거 / 소스 반영 상태 / 확인 필요 / 남은 일)
         docs/인수인계/00_프로젝트_현황.md (현재 기준값 표 / 남은 일 / 사용자 규칙·기억 요청)
4. "인수인계" 라고 하면: 위 두 파일을 정리해서 작성·갱신하고, 커밋·머지한 뒤 경로만 알려준다.
5. 변경이 생기면 작업을 끝내기 전에 반드시 레포 최상위에서 ./save.sh 를 실행해 전체 변경분을 커밋하고 main 에 머지(푸시)한 뒤 결과만 한 줄로 알려준다. ("커밋" 이라고 해도 같다.)
   ./save.sh 가 없으면 git add·commit·push 로 한다. 다른 브랜치에서 작업했으면 main 에 머지한다. 미완성 소스는 커밋 메시지에 "(작업 중)" 을 붙인다.
6. "기억해" 라고 한 내용은 00_프로젝트_현황.md 의 "사용자 규칙·기억 요청" 섹션에 한 줄로 추가한다.
7. 원본은 무조건 그 프로젝트의 깃 레포(main)다. claude.ai 프로젝트 문서·아티팩트·로컬 파일은 사본이며, 다르면 레포가 맞다. 수정은 레포에서 먼저 하고 사본을 레포에 맞춘다. 레포 주소는 프로젝트 지침이나 레포의 README/CLAUDE.md에서 확인하고, 없으면 먼저 물어본다.
8. 프로젝트가 삭제돼도 레포만으로 관리·복구할 수 있어야 한다. 대화에서 정한 것, 지침 문구, 주소·ID 같은 기준값은 모두 레포 문서에 남기고 커밋한다.
```
