# 복구 가이드 · 레포만으로 전부 되살리기

> claude.ai 프로젝트나 아티팩트가 지워져도 **이 레포만 있으면 전부 다시 만들 수 있어야 한다.**
> 그래서 작업에 필요한 모든 것(문서, 도구, 지침 문구, 주소·설정값)은 레포에 둔다.

## 1. 레포에 있는 것 (= 복구 재료)

| 필요한 것 | 레포 위치 |
|---|---|
| 작업 지침 (자동으로 읽힘) | `CLAUDE.md` |
| 모든 작품 공통 규칙·자료 | `docs/공통/` |
| 작품 문서 | `docs/작품/<작품>/` |
| 새 작품 양식 | `docs/작품/_템플릿/` |
| 구조·메뉴·버전 기록 | `docs/00_구조_안내.md` |
| 현황·기준값·남은 일·사용자 규칙 | `docs/인수인계/00_프로젝트_현황.md` |
| 작업 기록 | `docs/인수인계/YYYYMMDD_*.md` |
| claude.ai 프로젝트 지침 칸 문구 | `docs/관리/02_프로젝트_지침.md` |
| claude.ai 개인 설정 지침 문구 | `docs/관리/03_개인_지침.md` |
| 통합 자료집 소스 | `tools/hub.html`, `tools/editor.html`, `tools/presets/`, `tools/build.py` |
| 통합 자료집 결과물 | `site/index.html` |
| 커밋 스크립트 | `save.sh` |

## 2. 레포에 두지 않는 것 (다시 만들면 됨)
- claude.ai 프로젝트 자체, 프로젝트의 `claude/` 문서 사본
- 통합 자료집 아티팩트 (주소는 새로 생김)
- 대화 기록 — 대화에서 정한 것은 **반드시 문서로 옮겨 레포에 커밋**한다. 대화에만 있는 결정은 없는 것으로 본다.

## 3. 프로젝트가 지워졌을 때 복구 순서
1. claude.ai에서 새 프로젝트를 만든다 (이름: 로판ai영화).
2. 프로젝트 지침 칸에 `docs/관리/02_프로젝트_지침.md` 의 문구를 붙여넣는다.
3. 새 대화에서 Claude에게: **"https://github.com/similefor/Ai-drama 레포로 프로젝트 복구해 줘"** 라고 요청한다. Claude가 할 일:
   1. 레포를 받는다.
   2. 아래 '4. 사본 경로 규칙'대로 프로젝트 `claude/` 에 문서를 복사한다.
   3. `python3 tools/build.py` 로 `site/index.html` 을 만든다.
   4. 통합 자료집을 새 아티팩트로 발행하고, 편집기용 권한을 켠다 (capabilities: `sample`, `downloads`).
   5. 새 아티팩트 주소를 `docs/인수인계/00_프로젝트_현황.md` 와 `docs/00_구조_안내.md` 에 적고 **커밋·머지**한다.
4. 개인 설정 지침이 비어 있으면 `docs/관리/03_개인_지침.md` 문구를 넣는다.

## 4. 사본 경로 규칙 (레포 → claude.ai 프로젝트)

| 레포 | 프로젝트 |
|---|---|
| `CLAUDE.md` | `claude/CLAUDE.md` |
| `docs/<경로>` | `claude/<경로>` |
| `tools/<경로>` | `claude/tools/<경로>` |

- `site/`, `save.sh`, `README.md`, `.gitignore` 는 프로젝트에 복사하지 않는다.

## 5. 지켜야 할 것
- 새 기준값(주소·ID·결정)이 생기면 **레포 문서에 먼저 적고 커밋·머지**한다.
- 지침 문구를 바꾸면 `docs/관리/02·03` 도 같이 고친다.
- 프로젝트나 아티팩트에서만 고친 내용은 레포에 다시 옮기기 전까지 사라질 수 있는 것으로 본다.
